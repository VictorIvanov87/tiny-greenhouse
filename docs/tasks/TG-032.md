# TG-032 — Improve dashboard content density and data readability

**Type:** Enhancement
**Priority:** Medium
**Component:** frontend

**Goal**
The dashboard layout is structurally sound but the individual components under-use the space and surface less context than they could. Four targeted improvements — enriching the greeting card, increasing chart height + showing the Y-axis, removing the nested inner scroll from the telemetry table, and adding colour-coded sensor values — will make the dashboard meaningfully more informative without changing the page's overall structure or requiring new API endpoints.

---

## Current Behavior

### 1. Greeting card is static and context-free
`DashboardPage.tsx` lines 251–260. The card shows only the plant-type greeting and a fixed subtitle. It has no live indicators of greenhouse health or data freshness. A user returning to the tab has no way to see at a glance whether things are OK.

```tsx
<Card className="rounded-3xl mb-6 …">
  <h1 className="text-3xl font-semibold text-slate-100 sm:text-4xl">
    {greetingByPlant(profile.plantType)}
  </h1>
  <p className="text-sm text-slate-400">
    Here's the latest snapshot of your greenhouse performance …
  </p>
</Card>
```

### 2. Charts are too short and have no Y-axis scale
`ChartCard.tsx` line 30: chart area is `h-36 md:h-40` (144 px / 160 px). At that height, even moderate variance looks visually flat. Additionally, `DashboardPage.tsx` line 135 hides the Y-axis entirely (`<YAxis hide …>`), so there is no scale reference for any of the three charts.

### 3. `RecentTelemetry` has a fixed-height inner scroll box
`RecentTelemetry.tsx` line 58:
```tsx
<div className="h-[26rem] overflow-y-auto rounded-2xl border border-slate-100">
```
This creates a card-within-card scroll context: the outer card's right-side gutter fills with a second scrollbar on Webkit browsers, and the fixed 416 px height often either clips data or leaves an empty gap, depending on the row count.

### 4. Telemetry table cells are plain monochrome text
`RecentTelemetry.tsx` lines 81–83: temperature, humidity, and soil-moisture values are all rendered with the same default text colour. Out-of-range values are indistinguishable from normal readings at a glance.

## Expected Behavior

### 1. Greeting card shows live health status and last-seen time
Below the subtitle, add two inline indicators derived from data already loaded on the page:
- **Health badge**: green "All clear" when `active.length === 0` (from `useAlerts()`), amber "N warning(s)" for warn-severity alerts, red "N critical" for critical-severity alerts.
- **Last reading**: "Last reading: 3 min ago" computed from the most recent `sample.timestamp` in `sortedSamples`.

### 2. Chart area grows and Y-axis is visible
- `ChartCard.tsx` line 30: `h-36 md:h-40` → `h-52 md:h-60` (208 px / 240 px).
- `DashboardPage.tsx` line 135: remove `hide` from `<YAxis>`, add dark-themed axis ticks:
  ```tsx
  <YAxis
    domain={['auto', 'auto']}
    tick={{ fill: '#94a3b8', fontSize: 11 }}
    tickLine={false}
    axisLine={false}
    width={36}
  />
  ```

### 3. Telemetry table fills naturally without inner scroll
Remove the fixed-height wrapper in `RecentTelemetry.tsx`:
```tsx
// Before (line 58)
<div className="h-[26rem] overflow-y-auto rounded-2xl border border-slate-100">

// After — let the card grow with its content; clip only if extremely tall
<div className="max-h-[36rem] overflow-y-auto rounded-2xl border border-[#1f2a3d]">
```
The page shell (`main.flex-1.overflow-y-auto`) handles the outer scroll, so the table can expand naturally up to a generous `max-h` cap.

### 4. Sensor value cells use light colour-coding
Wrap each sensor value in a helper that returns a Tailwind text colour:
- **Temperature**: ≥ 35 °C → `text-rose-400`; ≤ 10 °C → `text-sky-400`; otherwise inherit.
- **Humidity**: < 30 % → `text-amber-400`; > 90 % → `text-sky-400`; otherwise inherit.
- **Soil moisture**: < 20 % → `text-amber-400`; otherwise inherit.

   - After loading, derive `healthStatus` from `active` array:

     ```ts
       ? null
       : lastSeenMs < 60_000

     ```

     ```tsx
     <div className="mt-3 flex flex-wrap items-center gap-3">

         <span className="rounded-full bg-rose-900/50 px-3 py-1 text-xs font-semibold text-rose-300">
     ```

## Acceptance Criteria

- Greeting card shows a correctly-coloured health badge and a "Last reading: N min ago" label whenever telemetry samples are loaded.
- Charts display at minimum 208 px height and show a Y-axis with dark-coloured tick labels.
- The telemetry table expands to fit its rows up to a `max-h` cap without an inner scrollbar at normal row counts (≤ 25 rows).
- Out-of-range temperature, humidity, and soil-moisture values render in the specified accent colours; normal values inherit the default text colour.
- `npm run build` succeeds with no errors.

## Notes for Agents

- `useAlerts()` is already available via `AlertsContext`. Import it at the top of `DashboardPage.tsx` alongside the existing imports.
- The `sortedSamples` variable is already computed on line 80 — use `.at(-1)` to get the latest sample rather than re-sorting.
- Threshold values (35 °C, 10 °C, 30 % RH, etc.) are reasonable defaults; they can be made configurable via profile in a follow-up.
- The Y-axis `width={36}` allocation prevents the axis labels from being clipped by the card padding — keep this value.
- After applying TG-031, the `border border-slate-100` in the old inner-scroll div will look wrong on the dark card — this step replaces it with `border-[#1f2a3d]`, so the fixes are complementary.
