# TG-031 — Unify dashboard cards to dark theme matching the app shell

**Type:** Bug
**Priority:** High
**Component:** frontend

**Goal**
The app shell (`AppShell.tsx`) renders a fully dark navy background (`bg-[#0b1220]` sidebar, `bg-[#0f1729]` main area). Every card on the dashboard — charts, KPI cards, recent-telemetry table, and the alert panel — uses Flowbite's default light theme: `bg-white` with `border-slate-200`. At runtime this creates four bright-white rectangles punched into a dark page, which looks unintentional and breaks the visual coherence the rest of the app achieves (the greeting banner and the assistant chat are already dark-themed correctly). A visual review at 1440 px confirmed the problem is immediately noticeable.

---

The following components use light card styles:

**`frontend/src/shared/ui/ChartCard.tsx` line 22**
```tsx
<Card className="min-w-0 rounded-3xl border border-slate-200 shadow-sm">
  <p className="text-sm font-semibold text-slate-900">{title}</p>
```

**`frontend/src/features/dashboard/components/KpiCards.tsx` line 57–58**
```tsx
<Card key={id} className="rounded-3xl border border-slate-200 bg-white shadow-sm">
  <p className="text-sm font-semibold text-slate-900">{metric.label}</p>
```

**`frontend/src/features/dashboard/components/RecentTelemetry.tsx` lines 46, 49, 60**
```tsx
<Card className="flex h-full flex-col rounded-3xl border border-slate-200 bg-white shadow-sm">
  <h2 className="text-lg font-semibold text-slate-900">Recent telemetry</h2>
```

**`frontend/src/features/alerts/AlertPanel.tsx` lines 23, 26**

For reference, the correctly-themed greeting card in `DashboardPage.tsx` line 251 uses:
```tsx
<Card className="rounded-3xl mb-6 border border-[#1f2a3d] bg-[#111c2d] text-slate-200 shadow-[0_24px_60px_rgba(8,20,38,0.35)]">
```

## Expected Behavior

All four components render dark cards that blend with the shell:
- Card background: `bg-[#111c2d]`
- Card border: `border border-[#1f2a3d]`
- Card shadow: `shadow-[0_24px_60px_rgba(8,20,38,0.35)]`
- Primary text: `text-slate-100`
- Secondary / label text: `text-slate-400`
- Table row dividers: `divide-[#1f2a3d]`
- Sticky table header background: `bg-[#111c2d]`
- Alert list item border: `border-[#22324a]` (one shade lighter than card border)
- Inner badge / chip backgrounds: `bg-[#0f1729]` with `border-[#22324a]`

## Scope

- Update card and text colour classes in `ChartCard.tsx`.
- Update card and text colour classes in `KpiCards.tsx`, including the Start/End pill badges.
- Update card, table header, and text colour classes in `RecentTelemetry.tsx`.
- Update card and text colour classes in `AlertPanel.tsx`, including individual alert list item borders.

## Out of Scope

- Changing any card used outside the dashboard (e.g. in `AlertsPage`, `SensorDataPage`) — those pages are covered by TG-029.
- Changing the greeting card in `DashboardPage.tsx` — already correct.
- Changing Flowbite's global theme config.

## Notes for Agents

- The colour tokens used here (`#111c2d`, `#1f2a3d`, `#0f1729`, `#22324a`) are already used throughout the app shell and the assistant chat — no new colours are introduced.
- `ChartCard` is also imported by pages other than the dashboard (e.g. if added to other routes in future). The dark style is safe to apply globally because the shell background is always dark in authenticated views.
- Do not change the Recharts `<Area>` stroke/fill colours — those are correct and readable on the dark card.
- Flowbite's `<Table>` component renders its own `<thead>` background via Tailwind. Override it explicitly with the `className` prop on `<TableHead>` as shown in step 3.
